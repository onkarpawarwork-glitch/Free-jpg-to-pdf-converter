# Future programmatic SEO URL plan

No landing pages are generated by this plan yet. Add a route only when it can provide useful, distinct guidance and accurately describe the converter.

## Target-size landing pages

Use the consistent, lowercase pattern `/jpg-to-pdf-under-{limit}/`:

- `/jpg-to-pdf-under-200kb/`
- `/jpg-to-pdf-under-500kb/`
- `/jpg-to-pdf-under-1mb/`
- `/jpg-to-pdf-under-2mb/`

## Document-specific landing pages

Use `/jpg-to-pdf-for-{document-purpose}/` for a specific document workflow:

- `/jpg-to-pdf-for-passport-photo/`
- `/jpg-to-pdf-for-signature/`

Keep route words lowercase, use hyphens between words, and spell size units consistently as `kb` or `mb`. Pages should explain that the selected size is a maximum target, not a guaranteed output size. Avoid near-duplicate pages; include requirements only when they can be supported by reliable, current sources.
